Getting started

Set up your first automation in ten minutes

5 min read · Updated 29 October 2026

This walkthrough takes you from a fresh account to a live automation on a single post. If something doesn't behave the way this page describes, see troubleshooting.

Before you start

  • An Instagram Creator or Business account (not personal).
  • A Facebook page linked to that account — Instagram requires it for API access.
  • One post or reel you'd like to test on. Pick something with real comments.

1. Connect the account

From the workspace, choose Connect Instagram and approve the requested permissions. You'll be returned to Viraloop with the account listed and a green status. See connect your Instagram account if the connection fails.

2. Create the automation

Choose New automation, then pick the post or reel. Give it a name you'll recognise later — “Price list — launch reel” beats “Automation 3”.

3. Add keywords

Enter the phrases people actually type: price, pricing, cost, how much. Matching ignores case but is otherwise literal, so add the variations you see in your comments.

4. Write the DM

Two sentences: what this is, and what to do next. Preview it — the preview is exactly what the follower receives, including how the link renders.

Keep the first message short. A wall of text in a DM reads like spam, and long messages get skimmed rather than read.

5. Test before going live

Use Send test to deliver the message to your own account. Check the link, the tone and the fallback text. Then switch the automation to Live.

6. Watch the first day

Open the log after a few hours. You're looking for three things: whether the keywords matched the comments people actually left, whether the DM copy produced replies, and whether anyone needed a human. Adjust keywords first — it's the cheapest fix.
