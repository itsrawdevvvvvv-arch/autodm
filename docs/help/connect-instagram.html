Connect your Instagram account

5 min read · Updated 29 October 2026

There are two ways to connect: the Connect Instagram button, which runs Meta's standard authorisation flow, or pasting a long-lived token by hand. Both end in the same place.

The one-click flow

  1. Press Connect Instagram in the dashboard (or on the connect page).
  2. Instagram opens its own permission screen. Approve the three scopes listed below.
  3. You land back in the dashboard with the account connected and polling already running.

Behind that: the app sends you to instagram.com/oauth/authorize with a one-time state value, exchanges the returned code for a long-lived token (~60 days), and stores it on your server only.

The three permissions

  • instagram_business_basic — your profile and media list, so the app knows which posts to watch.
  • instagram_business_manage_messages — read and send DMs, so it can reply.
  • instagram_business_manage_comments — read comments, so it can spot keyword matches.

Requirements

  • An Instagram Creator or Business account.
  • A Meta app with the Instagram product added, and your account added as a tester.
  • META_APP_ID and META_APP_SECRET set on the server.
  • PUBLIC_URL set to your deployed https URL, and that exact URL registered as a Valid OAuth Redirect URI (ending /auth/callback).

The dashboard tells you which of these is missing: open Account and read the setup note, or hit /api/oauth-check on your server.

Connecting with a token instead

In the Meta dashboard, generate a long-lived token with the three scopes above and paste it into Account → paste an access token. Useful when you can't set up a redirect URI, or when you want to connect on a machine with no public URL.

Revoking access

Dashboard → Disconnect deletes the stored token. To revoke at Meta's side as well, remove the app in Instagram → Settings → Apps and websites. Disconnecting stops all automations immediately.

Common errors

  • Invalid redirect URI — the registered URI and PUBLIC_URL differ. They must match character for character, https included.
  • App in development mode — add your account as a tester on the Meta app; no app review needed for personal use.
  • Insufficient permissions — a scope was declined. Reconnect and approve all three.
  • Link expired — the state value is only valid for ten minutes. Press Connect again.
